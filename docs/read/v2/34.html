第二卷 · 明天一定

造一个

第 34 章 · 3,999 字 · 约 9 分钟

4月23日，星期四，下午三点。

陆沉在做数学。

他按教材的顺序复习，复习到微分中值定理。

定理他都会背：罗尔、拉格朗日、柯西。条件、结论、几何意义，一条一条，背得很顺。例题他也看得懂，跟着走一遍，走完觉得“就这么回事”。

然后他做课后题。

第一道：

设 f(x) 在 [0,1] 上连续，在 (0,1) 内可导，f(0)=0，f(1)=1。证明：存在 ξ∈(0,1)，使得 f'(ξ)=2ξ。

他先试拉格朗日。f(1)-f(0) 除以 1-0，等于 1。所以存在 ξ，f'(ξ)=1。

1 不等于 2ξ。

他试柯西。取 g(x)=x²，那么

f'(ξ)/g'(ξ) = [f(1)-f(0)]/[g(1)-g(0)] = 1/1。

g'(ξ)=2ξ。

所以 f'(ξ)=2ξ。

证完了。

他看了看表：三点十二。开始做是三点零五。

七分钟。其中三分钟在算，两分钟在怀疑自己算错，剩下两分钟在反复看题干。

他有点不敢相信，又检查了一遍条件。都满足。

以前这种题，他要看答案。看完会说“哦，原来是这样”，然后把答案抄进本子，抄得很整齐，抄完就再也不看。

这次他没看答案。

＊　＊　＊

四点，他做到第二道。

设 f(x) 在 [0,1] 上连续，在 (0,1) 内可导，f(0)=0，f(1)=1。证明：存在 ξ∈(0,1)，使得 f'(ξ)=f(ξ)/(1-ξ)。

他盯着这道题，看了十分钟。

没有思路。

要证的东西里，f' 和 f 都在，右边还除以一个 (1-ξ)。

他试着移项：

f'(ξ)(1-ξ) - f(ξ) = 0。

这个形式他很熟。前几天刚做过类似的题，都是“乘一个 e 的什么东西，让乘积的导数等于零”。

他写下：

(e^{-x}f(x))' = e^{-x}[f'(x) - f(x)]。

不是他要的。

(e^{x}f(x))' = e^{x}[f'(x) + f(x)]。

也不是。

他要的是 f'(x)(1-x) - f(x)。

这个式子里有一个 (1-x)，不是常数，是 x 的函数。乘 e 的办法在这儿不起作用。

＊　＊　＊

四点四十，他换了个方向。

他把 f'/f 单独拿出来，当成一个微分方程：

f'(x)/f(x) = 1/(1-x)。

两边积分，ln f = -ln(1-x) + C。

所以 f(x) = C/(1-x)。

这个式子告诉他：如果 f 真的满足那个等式，它应该是这个形状。

但 f 是任意的，只满足两个端点条件。

说明这个思路只能看方向，不能拿来证。

他在草稿纸上写：

要证的是“某一点成立”，不是“处处成立”。

所以还得靠中值定理。

＊　＊　＊

五点十分，他卡住了。

他去接了一杯水，回来的时候，看见陈姐推着车经过。

图书馆后院有一只橘猫，不知道谁起的名字，陈姐管它叫“馆长”。这会儿它正蹲在台阶上，看一只苍蝇。

陆沉路过的时候，它抬头看了他一眼，又低下去。

“别喂它。”陈姐说，“喂了就不走了。”

“我没带吃的。”

“带了也不能喂。”她说，“上个月有个小姑娘天天喂，喂到它挑食，火腿肠都不吃，只吃鸡胸肉。”

“猫还挑这个？”

“猫精着呢。”

他站起来让路。

陈姐看了他一眼，看了看他的草稿纸。

“做不出来？”

“嗯。”

“多久了？”

“一个多小时。”

“什么题？”

他把纸推过去。

陈姐看得很慢，手指在纸上点着。

“这个符号是什么意思？”

“导数。”

“哦。”她点点头，“我以前教初中，没教过这个。”

“嗯。”

她继续看，看了一会儿，忽然说：

“你们这种题，是不是要先自己造一个东西出来？”

陆沉愣了一下。

“什么意思？”

“我儿子以前做题，老想不出来。”陈姐说，“后来他们老师说，想不出来就自己先造一个。造一个跟题目长得像的，再看它满不满足条件。”

“造一个函数。”

“对，就这个意思。”她说，“我儿子那年考大学，差两分。他要是会造，说不定就考上了。”

她推着车走了。

＊　＊　＊

陆沉坐下来。

“造一个跟题目长得像的。”

他把这句话写在草稿纸最上面。

然后他盯着要证的那个式子：

f'(ξ)(1-ξ) - f(ξ) = 0

左边像什么？

像两个东西相减。

一个是 f'(x) 乘 (1-x)，一个是 f(x)。

如果有一个函数，它的导数正好是这两项相减，那就成了。

他试着把 (1-x) 当成一个普通的因子，往乘积求导公式里套：

(uv)' = u'v + uv'。

要让 uv 的导数等于 f'(1-x) - f，那么一项是 f'，一项是 f。

取 u=f，v=(1-x)。

(f(x)(1-x))' = f'(x)(1-x) + f(x)·(-1) = f'(x)(1-x) - f(x)。

他把笔停住。

就是这个。

＊　＊　＊

五点二十五，他写下：

令 g(x) = f(x)(1-x)。

g(0) = f(0)·1 = 0。

g(1) = f(1)·0 = 0。

g 在 [0,1] 连续，在 (0,1) 可导。

由罗尔定理，存在 ξ∈(0,1)，使 g'(ξ)=0。

g'(x) = f'(x)(1-x) - f(x)。

所以 f'(ξ)(1-ξ) - f(ξ) = 0。

因为 ξ∈(0,1)，1-ξ ≠ 0，两边除以 (1-ξ)：

f'(ξ) = f(ξ)/(1-ξ)。

写完，他把笔放下。

手有点抖。

不是激动。是那种绷了两个多小时、忽然松开的感觉。

＊　＊　＊

他看着这三行字，忽然明白了一件事。

刚才他一直想“乘一个 e”，因为前面几道题都是那么做的。他把“构造辅助函数”理解成了“找一个指数函数”。

其实不是。

辅助函数不是从天上掉下来的，是从要证的式子里长出来的。要证的式子里有 f 和 f'，还有 (1-x)，那它就像 (f·(1-x)) 的导数。你把它反着拆回去，它就出来了。

陈姐不知道什么叫导数。她只是说了一句她儿子老师说过的话：造一个。

他造出来了。

＊　＊　＊

五点四十，他做第三道。

设 f 在 [0,1] 连续，(0,1) 可导，f(0)=0，f(1)=1。证明：存在 ξ∈(0,1)，使 f'(ξ)=f(ξ)-ξ+1。

他先移项：

f'(ξ) - f(ξ) + ξ - 1 = 0。

有 f' 和 f，系数是 1。他试着乘 e^{-x}：

(e^{-x}f(x))' = e^{-x}[f'(x) - f(x)]。

这个东西等于零，意味着 f'=f。

但题目要的是 f' - f = 1 - ξ。

他把两行并排写：

要证：e^{-x}[f'(x) - f(x)] = e^{-x}(1 - x)

已经有：(e^{-x}f(x))' = e^{-x}[f'(x) - f(x)]

那么右边那项 e^{-x}(1-x) 是谁的导数？

他算了几种。

(e^{-x})' = -e^{-x}，不对。

(xe^{-x})' = e^{-x} - xe^{-x} = e^{-x}(1-x)。

对上了。

所以 e^{-x}(1-x) = (xe^{-x})'。

把两边合起来：

[e^{-x}f(x)]' - [xe^{-x}]' = 0

也就是

[e^{-x}(f(x)-x)]' = 0。

他停住，看着这一行。

刚才那道题，是乘一个东西让两端相等。

这道题，是把两个导数合起来。

他写下：

令 g(x) = e^{-x}[f(x)-x]。

g(0) = 1·(0-0) = 0。

g(1) = e^{-1}·(1-1) = 0。

g 连续、可导。

由罗尔定理，存在 ξ∈(0,1)，使 g'(ξ)=0。

g'(x) = e^{-x}[f'(x)-f(x)+x-1]。

e^{-x} 恒不为零，所以 f'(ξ)-f(ξ)+ξ-1=0。

即 f'(ξ) = f(ξ) - ξ + 1。

写完，他往椅背上一靠。

窗外的天已经开始暗了，五楼这边的灯亮了一半，另一半点着几盏。

他低头看了看草稿纸。

三张纸，写得满满的。有划掉的，有写错的，有一行写到一半改成另一种颜色的。

以前他的草稿纸很干净。因为他从来不在纸上想，他在答案里想。

＊　＊　＊

六点十分，他合上笔。

第三道题的答案他没有对。他把草稿纸折好，夹进文件夹，站起来，收拾东西。

六点二十，下楼。

陈姐在前台锁抽屉。

“做出来了？”

“做出两道。”

“那不错。”她把钥匙放进包里，“我儿子当年有不会的题，也是第二天再做。他说睡一觉，有时候就通了。”

“嗯。”

“不过他也说过一句话。”陈姐说，“他说，有的题一辈子也通不了，那就别通了，背下来。”

陆沉笑了一下。

“那我先背。”

“先背。”陈姐说，“背会了再通。”

＊　＊　＊

七点，他骑车回家。

风很软，江面上有货船的灯。

小区门口在修路，挖开一条沟，两边用红白相间的塑料围栏挡着。一个工人坐在围栏上抽烟，安全帽挂在膝盖上。

陆沉推着车从旁边绕过去。

“哎，小伙子。”工人说，“明天这儿过不了，走东门。”

“东门在哪儿？”

“绕一圈，多走三百米。”

“行。”

“你这车不错。”工人看了看他的电动车，“能跑多远？”

“二十多公里。”

“那够用了。”工人说，“我那个跑四十，电池不行了。”

楼道里有一股炒菜的味，三楼在炸鱼，五楼在炖排骨。他打开门，屋子里是干的，什么味都没有。

他打开错题本，翻到最后一页，新开了一栏：

做出来的

第一行：

4.23　f'(ξ)=f(ξ)/(1-ξ)　构造 g=f(x)(1-x)，罗尔

第二行：

4.23　f'(ξ)=f(ξ)-ξ+1　构造 g=e^{-x}(f(x)-x)，罗尔

写完，他退后一点看。

两行字，两道题。

六个小时。

按以前的标准，这个效率低得可笑。以前他一天能“看”五十道题，全都能看懂。

今天他做了三道，三道都没看答案。

＊　＊　＊

睡前，他打开群。

路人甲：有没有人四月才开始

应届小赵：我三月开始的，现在数学第二章。

西交差3分：我去年四月开始的。

管理员-阿凯：四月不晚。八月也有人说晚。

路人甲：那我现在开始还来得及吗

管理员-阿凯：来得及，先别看群。

陆沉笑了一下，退出去。

然后他打开那个对话框。

输入框空着，光标在闪。

他想把两道题的证明贴进去，问一句“我这样对不对”。

手指停在键盘上。

过了一会儿，他退出去，锁屏。

明天再说。明天先自己检查一遍，再问。

他躺下，关了灯。

黑暗里，他还在想一件事：今天这两道题，为什么会做出来。

不是因为聪明。

是因为他在纸上待够了时间。

以前他也坐在桌前，一坐十个小时。但那十个小时里，他的眼睛在字上，脑子在别处。他在等一个答案，等一个计划，等一个“从明天开始”。

今天他什么都没有等。

他只是不会，然后继续想。
