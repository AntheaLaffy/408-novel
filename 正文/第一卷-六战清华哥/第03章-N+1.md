# 第03章 N+1

3月12日，星期四。

十点二十五，陆沉把杯子洗了，接满水，放到工位上。他也不知道自己为什么要先做这件事，可能是觉得回来以后还会渴。

十点半，蒋文斌从工位站起来，说：“走吧。”

两个人往 3F 小会议室走。走廊不长，二十来步，中间经过一面贴满项目照片的墙。照片里有一张是去年团建，十几个人挤在一起，蒋文斌站在最边上，手里举着一串烤韭菜。陆沉在那张照片里，站在第二排，笑得很客气。

小会议室的门关着。蒋文斌敲了两下，推开。

何丽已经坐在里面了。

她是部门的 HRBP，三十多岁，说话一直很稳。桌上摆着一个文件夹，三杯水，三把椅子。靠门那把是给陆沉留的。

陆沉坐下，摸了一下杯子。

温的。

不是刚倒的，是提前倒好的。这个细节让他忽然很难受。它说明这场谈话的时间、顺序、谁坐哪儿，都已经安排完了，只剩下他走进来。

何丽先开口。

“陆沉，感谢你这两年对公司的付出。基于业务结构的调整，你所在的岗位需要做一些优化。”

她的声音很平，像一段念过很多遍的话。

“公司这边给出的方案是 N+1。你的月薪是一万三，两个月，两万六。社保交到三月底。本周内完成交接。这是协议，你可以带回去看，也可以现在签。”

陆沉把协议翻了两页。纸很白，字很小，第三条写着“双方确认不存在其他劳动争议”。

“为什么是两个月？”他问。

何丽看了他一眼，翻开文件夹里的另一张纸：“你的劳动合同是 2024 年 9 月签的，到这个月是一年半。”

“我 2024 年 7 月就来了，实习加试用。”

“是的，但是 2025 年 1 月公司做过一次主体变更，工龄从新主体起算。”

陆沉想了一下。

2025 年 1 月，公司确实换了签约主体。当时发过一封邮件，说是“集团架构优化”，让大家重签一份合同，福利不变。他记得自己签得很快，因为那天下午要上线一个需求。

“所以按一年半算，是 N 等于一点五，四舍五入……”

“N 按一年算。”何丽说，“N+1 是两个月。这是公司统一的算法。”

“有人不同意吗？”

何丽没有回答这个问题。她说：“你也可以选择走仲裁。这是你的权利。”

她说得很平静，好像只是在陈述一个流程。陆沉忽然意识到，这句话她也说过很多遍。

他看了看蒋文斌。

蒋文斌一直没说话，坐在靠窗的位置，手里转着一支笔。见他看过来，蒋文斌把笔放下，说：“陆沉，这个不是我能定的。”

“我知道。”

“你的代码挺干净的。”蒋文斌说，“就是现在这个岗位，不需要那么多人了。”

这句话陆沉听过一次。去年第一轮裁员的时候，蒋文斌在全员会上说过类似的话，那时候被说的是别人。

他低下头，把协议翻到最后一页。

签名栏空着，旁边有一行小字：请使用黑色签字笔。

桌上有一支黑色签字笔。

他拿起来，写下自己的名字。三个字，写得比平时工整。

---

交接对象是周晓枫。

周晓枫搬了把椅子过来，把笔记本电脑放在陆沉桌上，两个人对着一台屏幕。

“Git 权限、测试环境、生产只读库、日志平台、还有个 Jira 的管理员。”陆沉一项一项念，“管理员你让蒋哥去改，我这边没权限移交。”

“行。”

“`report-export` 那个分支别直接合，里面有个字段是客户自己加的，合了会炸。”

“行。”

“这个定时任务每月一号跑，如果那天是周六，会重复执行一次。我加了个判断，但没验证过。”

“行。”周晓枫记下来，忽然问，“你为什么没验证？”

“因为那天是周六。”

周晓枫笑了一声，没再问。

“这个模块的注释是我去年写的，写着 TODO 的地方其实我都做完了，忘了删。”

“行。”

“这个……”陆沉停了一下，“这个接口的超时时间被人改过，从三秒改成十秒，我不知道是谁改的，也不知道为什么。你上线前看一眼。”

“什么时候改的？”

“去年十一月。”

周晓枫看着那条提交记录，皱了皱眉：“是灵犀改的。工单 4471，客户说详情页加载慢。它把超时时间放大了。”

“那问题解决了吗？”

“没有。它只是让报错变成了慢。”

两个人沉默了一会儿。

“对了，”周晓枫想起一件事，“启明那个时区，是谁加的？”

陆沉查了一下提交记录：“灵犀。去年 8 月，工单 4162，客户说详情页时间不对。它加了一层转换，没注意两边用同一个 VO。”

“谁评审的？”

“评审也是它。”周晓枫耸耸肩，“双 Agent 互评，通过了。”

“所以我这两天在修 Agent 写的 bug。”

“你在修 Agent 没 review 出来的 bug。”周晓枫纠正他，“我们都一样。”

陆沉把交接清单打印出来，签了字。周晓枫也签了。

“要内推的话跟我说。”周晓枫站起来，拍了拍他的肩，“别客气。”

“嗯。”

“真心的。”周晓枫说，“你基础不差，就是懒。你要是愿意把看 Agent 代码的时间拿出一半来自己想，你不至于。”

“我现在说‘我会的’，你信吗？”

“不信。”周晓枫说，“但我会等你做到的那天再说。”

---

下午三点，陆沉开始收拾工位。

抽屉里的东西比他想象的多。

半盒胃药。两包没拆封的速溶咖啡。三张过期的外卖满减券。一个 2024 年秋招时发的工牌套。一个坏掉的鼠标。还有一本《计算机网络：自顶向下方法》。

那本书是 2022 年买的，塑封只拆了一半。他当时打算“系统补一遍基础”，拆封的那一半，是为了看目录。

他把书塞进纸箱，忽然觉得这个动作很眼熟。

2024 年 7 月，他从学校搬出来，也抱着一个纸箱。里面装着同样的书，同样的胃药，同样的、没有开始过的计划。

区别是那时候他二十二岁，觉得一切都还来得及。

四点，他被移出了公司大群。

群名从“云枢科技-全员”变成一个灰色的提示：你已被移出群聊。

五点，钉钉头像变成灰的。系统提示：该员工已离职。

五点二十，他抱着纸箱走出写字楼。

江城的春天来得比往年早，路边的玉兰开得毫无节制。他站在楼下，看见唐宇也从旋转门里出来了，怀里抱着一个纸箱，箱子上面放着他那三个手办。

两个人对看了一眼。

唐宇想说点什么，最后只是点了点头。陆沉也点了点头。

他们连“保重”都没有说。

---

回出租屋的路上，他打开了招聘软件。

Java 后端开发，江城，一到三年经验。筛出来一百二十七个岗位。

第一个：8–12K，要求熟悉 Spring Cloud，熟悉 Agent 编排与 MCP 工具接入，能独立完成模块设计与开发。

第二个：7–10K，要求有 Agent 工作流落地经验，能对 Agent 产出做有效评审，了解 RAG 优先。

第三个：9–13K，AI 应用工程师，负责维护公司内部 Agent 平台的提示词与评测集，“有计算机相关专业背景优先”。

第四个：6–8K，外包驻场，长期出差。

第五个：5–7K，AI 数据标注员，负责对大模型输出进行质量评估，要求“有较强的文字理解能力”。

他一个个点进去，又一个个退出来。

第一个岗位的 JD 里有一句话：**能独立完成模块设计，不依赖 AI 完成核心逻辑。**

他看着这句话，想起自己昨天下午关掉灵犀，写二十分钟分页写不出来。

第二个岗位说“有 Agent 工作流落地经验”。他配过 MCP，配到第三天，一个工具连不上测试库，他就把这事放下了。

第三个岗位要求“了解大模型能力边界”。他忽然发现，自己连“灵犀什么时候会犯错”都说不清楚。他只知道它会犯错，但他不知道它会在哪里犯，为什么犯。

他上个月的工资是一万三。房租两千七，水电网两百，通勤两百，吃饭一千五，给林知遥过生日花了八百，还能剩七千多。他本来觉得这个数字不错，甚至计划过今年换一台显示器。

现在他算了一下。

补偿两万六，加存款四万一，一共六万七。

如果按每个月四千五的开销算，能撑十四个月。

十四个月。

这个数字在他脑子里转了一圈，忽然变成了另外一个东西：如果什么都不干，专心准备一场考试，十四个月是够的。

他被自己这个念头吓了一跳，赶紧又打开招聘软件，把那五个岗位重新看了一遍。

然后他把手机按灭，坐在路边的花坛沿上，看着对面写字楼的灯一层一层亮起来。

手机在口袋里震了一下。

是林知遥。

**“今天几点下班？”**

他盯着这条消息，看了很久。

他打了一行字，删掉。又打了一行，又删掉。最后他什么都没发，把手机翻过来，扣在膝盖上。
